# National source inventory, 2024–25

This inventory covers all 50 states. It records source availability and same-year identities; it does not mark a state ready in the browser. The approved eight-state direct-certification adapter is documented separately in [CCD state data](ccd-state-data.md). State income and assessment definitions remain separate.

The table's obstacles describe the initial national EDC/CCD path, not current readiness; state-native adapters can resolve them, and [state expansion](state-expansion.md) is the current release queue.

The official CCD membership file contains 11,172,292 records. Directory, membership and direct-certification files contain authoritative identifiers and raw missingness flags for all 50 states. Twenty states have EDC school G38 math/ELA rows; thirty require a native-total source or independently audited complete-grade aggregation weights. Numeric DC is absent in 17 states. These paths cannot be completed by using FRPL as an automatic substitute.

Preliminary join counts use numeric highest offered grade, exact-rate subject pairs, reported positive membership and reported DC. They precede the stricter approved adapter rules for complete grade subtotals, adjusted/unknown grade flags and known LEA allocation. They are not model populations: Rhode Island falls from 219 preliminary joins to 214 Combined model members after these additional exclusions. Indiana and Massachusetts use their separately approved state-native income adapters.

Native G38 provenance is the SEA grade-total designation in the [EDC v3.1 codebook](https://www.eddatacenter.org/data_codebooks/EDC_codebook_v3.1.xlsx). EDC overall rates may be sums of achievement-level percentages within the native total. Its constructed level counts and unverified tested values never establish interval denominators. The [technical documentation](https://www.eddatacenter.org/data_documentation/EDC_technical_documentation_v3.1.pdf) records state cohorts, standards and source modifications. High schools are outside this EDC grades 3–8 path.

The CCD [school lunch Final 2a](https://nces.ed.gov/ccd/Data/zip/ccd_sch_033_2425_l_2a_073025.zip), [membership Final 1a](https://nces.ed.gov/ccd/Data/zip/ccd_sch_052_2425_l_1a_073025.zip) and [directory Final 1a](https://nces.ed.gov/ccd/Data/zip/ccd_sch_029_2425_w_1a_073025.zip) all describe school year 2024–25. Final 2a is the latest lunch release, June 2026; Pennsylvania and South Carolina lunch values are suppressed for quality. The [SEA notes](https://nces.ed.gov/ccd/xls/SY_2024-25_CCD_Final_2a_Data_Notes.xlsx) supply concrete allocation and definition blockers.

[Machine-readable audit](../data/source/national-snapshot-audit.json) includes exact file URLs/checksums, source schemas, per-state grade and assessment counts, raw flag counts, preliminary school IDs and exclusion totals. [The broader state ledger](state-expansion.md) tracks implementation separately. Reproduce the source inventory with `.venv/bin/python scripts/audit_national_sources.py`; downloading EDC is explicit via `--download-edc`. Large raw files remain ignored under `data/raw/`.
